## Eligibility & Team Rules

* Open globally (must be legal age of majority in country of residence, excluding standard sanctioned regions).
* You can participate as an individual or in teams of any size.
* Existing projects are allowed only if **meaningfully extended with WebMCP** during the hackathon period (August 25 - September 3, 2026). Pre-existing WebMCP code does not count.

---

## 4 Mandatory Submission Deliverables

### 1. Live Working URL
* Must be accessible to judges via ChatGPT's in-app browser or Chrome with `#enable-webmcp-testing` turned on.
* Allowed hosting: Vercel, Cloudflare Pages/Workers, Netlify, Render, ChatGPT Sites, Shopify, etc.
* If authentication is required, provide test credentials in the Devpost submission notes.

### 2. Public Code Repository
* Must be hosted on GitHub, GitLab, or Bitbucket.
* Must include an open-source license file (MIT, Apache 2.0, etc.) in the root folder, visible in the GitHub "About" section.
* Must contain all source code, assets, and documentation to run the project.

### 3. Demo Video
* Maximum 3 minutes in length.
* Hosted on YouTube as Public or Unlisted.
* Must include clear audio voiceover explaining what was built and demonstrating live WebMCP tools in action.

### 4. Written Description
Must directly answer these four questions:
1. Why is your use case a strong fit for WebMCP?
2. How does it create a better user experience than traditional chat or UI clicks?
3. What can people and agents do together that was difficult or impossible before?
4. How did you implement WebMCP (technical architecture)?

---

## Judging Criteria (100% Total)

1. **WebMCP Leverage:** Depth and skill in tool implementation. Code demonstrates genuine utility with well-structured schemas and execution logic.
2. **Execution:** Completeness of the user experience. Polished UI, working end-to-end flows, resilient error handling.
3. **Potential Impact:** Clear solution to a real-world problem for a specific user audience.
4. **Creativity & Ambition:** Novelty in human-agent co-piloting and originality of concept.
